# Genre notes

These adjust the default structure in SKILL.md; they don't replace it. Each list comes from a real trailer session and the user's guidance for that genre.

## Metroidvania

- Show crisp movement first: dash, wall jump, mobility.
- Flash-cut several distinct biomes.
- Show a locked door or a high ledge, then the ability that opens it.
- Show a quick glimpse of the map UI.
- Show varied combat beyond basic slashes, and 2–3 distinct bosses.
- Let the music breathe, and follow it with the cuts.
- Hook within 5 s, run 45–60 s, and end on a clear call to action: the demo, if one exists.

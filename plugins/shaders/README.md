# shaders

`godot-shader-techniques`: non-trivial Godot 4.6+ shaders. Coordinate spaces and matrices, custom `light()` models, linear vs sRGB, normal maps and TBN, procedural SDF shapes, vertex displacement and billboards, post-processing, palette filters, Shadertoy ports, transparency and depth, ray marching, stencil.

Install: `/plugin install shaders@godot-agent` after `/plugin marketplace add dannroda/godot-agent-plugins`.

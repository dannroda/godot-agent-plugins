# godot-testing

- `godot-visual-test`: play a scripted run, save screenshots at checkpoints, and compare them with approved images.
- `godot-performance`: run the same stretch before and after a change, and compare frame, GPU and script time, draw calls, nodes and memory.

Each skill includes its scripts. Needs Godot. Checked on Godot 4.7.2 with a real game (Forward+, GPU rendering).

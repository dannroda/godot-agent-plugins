# blender

- `blender-scripting`: build, check and preview game assets with headless Blender Python.
- `blender-to-godot`: export to glTF and get the expected nodes, collisions, materials and animations in Godot.

Needs Blender on the machine; `blender-to-godot` also needs Godot to check the import. Facts were checked by running them on Blender 5.2.3 and Godot 4.7.2.
